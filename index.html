Wikipediaタガーについて

特徴と仕様

  • 完全クライアントサイド静的動作: バックエンドサーバー不要。ブラウザ標準のストリーミングGZIP解凍（DecompressionStream）と Web Worker により、クライアント側で約208万語の辞書を高速展開・照合。
  • 最長一致（Greedy Longest Match）: 複合語や長い専門用語（例:「量子コンピュータ」「人工知能」）を優先してマッチングします。
  • ポップアップ閲覧: 注釈用語をクリックすると、指定サイズの別ウィンドウでWikipedia該当記事が即座に開きます。
  • オフライン完結 & 高速キャッシュ: 初回ロード後はブラウザの Cache API に保持されるため、外部Web APIの通信制限や遅延がなく、完全オフラインかつミリ秒単位で処理可能です。
  • 入力文字数制限 & セキュリティ保護: 大量データ投入防止のため1回あたり最大2,000文字に制限。またJavaScriptインジェクション対策として、危険文字・制御文字（', ", \, \n, \r, \t, &, <, >）を入出力時に完全エスケープします。

除外規則と留意事項

すべての単語がハイライトされるわけではありません。文脈の可読性を保つため、以下のルールを適用しています：

  1. 空白・アンダースコア（_）を含む記事タイトル
  2. ひらがな1文字および極めて短い日常語
  3. 日本語の基本語彙（Wiktionary基本語彙・助詞・助動詞等）
  4. 曖昧さ回避括弧 () を含むタイトル

本アプリケーションについて:

本ツールは、東京大学の「Wikipediaタガー（Akira Maeda氏 開発）」のコンセプトと設計思想を参考に、内部組み込みダンプによる超高速アーキテクチャと現代的なWeb UI/UXで再構築したものです。
